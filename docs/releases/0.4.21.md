# Chord Control 0.4.21

## 浏览器保护退役

- 移除浏览器保护 `com.chord.study-guard` 的源码、界面和构建入口，不再拦截 Chrome／Edge 启动。
- 原目录发布者在签名目录中明确退役 1.3.2 及更早版本；客户端升级到 0.4.21 后，在同步目录或启动读取已缓存声明时自动卸载。
- 密保盘、程序入口保护、系统信息、壁纸策略和运行遥测保留；入口保护不再将退役浏览器插件列为受保护对象。

## 安全自动卸载

- 新增签名覆盖的 `retiredPlugins`：限定插件 ID、版本上限和最低主程序版本，不以目录缺失作为删除依据。
- 只处理仍绑定当前目录与原发布者公钥的安装；独立清单、其他目录、其他签名者、更高插件版本和未签名开发目录不会被自动删除。
- 先按依赖顺序执行生命周期清理，暂停依赖者，再移除安装记录；清理失败时保留记录，不能在重试中因运行时已脱离而跳过错误。
- 保留用户数据与旧版壁纸迁移日志，只清理不再被其他安装共享的程序缓存；普通下架和切换来源仍保留原安装。
- 即使关闭插件自动更新，也会处理已验证的明确退役声明。

0.4.20 及更早版本不会处理新退役表，必须先升级主程序。正式生产产物继续由 CI 构建。

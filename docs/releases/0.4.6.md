# 0.4.6

- 升级 Chord 至 0.86.1，继续支持已安装的 0.85.1 签名插件。新构建的插件声明需要主程序 0.4.6，避免更新时运行时不匹配。
- 控制中心、插件页面与遥测后台统一使用 SvelteKit，路由入口与业务会话分离；共享 Bits UI 组件提供一致的交互，密保服务使用独立契约包。
- 各页面应用采用独立工作区和 Kit 标准目录，配置合并至 Vite；插件页面继续输出单个 HTML 并独立签名更新。
- 统一控制中心、插件与遥测后台的配色，使用 OKLCH 调整色阶，并按实际背景校验文字对比度。
- 修复同版本插件重启后排队旧页面仍可调用，以及遥测后台退出和切换设备时旧响应覆盖页面的问题。
- 密保盘面板显示完整预览；验证窗口加载新页面后再显示，关闭时释放旧页面，避免重复打开闪出旧错误。
- 原生调用失败保留插件、执行进程身份、API 阶段、Windows 错误码和目标名称；不记录注册表值内容。
- 运行遥测 1.1.0 随插件独立编译和分发 Windows 只读采集器，采集 UAC、指定进程权限令牌和失败注册表目标的 DACL 检查结果。采集失败不会阻断已有状态上报。
- 修复同一更新组回退时把某个插件错误记录到其他插件的问题；恢复旧版本后仍保留真正失败插件的诊断。

权限检查反映采集时的状态，不能单凭“拒绝访问”确定某款安全软件拦截。后台分别展示采集失败、DACL 允许/拒绝和缺少厂商证据的情况。

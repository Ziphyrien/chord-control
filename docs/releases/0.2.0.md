# Chord Control 0.2.0

Windows x64 安装包：`Chord.Control-setup.exe`。内嵌运行时，无需额外安装 Node.js。

- Windows 注册表、壁纸、进程查询与启动改用 Rust 原生 API，移除插件运行时 PowerShell。
- 浏览器与壁纸策略继续由插件实现；宿主只提供通用能力和声明权限检查。学习权限插件 1.1.0 要求宿主 0.2.0。
- 修复插件窗口 label、显隐切换、更新后地址刷新、验证超时，以及控制器恢复逻辑。已安装插件从本地恢复后可直接响应桌面操作，按设置周期检查 GitHub。
- 主程序与守护进程互相监测并有界重启。正常退出、维护和升级会撤销当前会话并停止守护。
- 安装器默认登录启动，不生成卸载程序、不登记卸载项、不创建开始菜单或桌面快捷方式。维护停止与移除方法见 [维护说明](../maintenance.md)。
- 接入 Tauri 签名主程序更新：托盘检查并安装，先验签再停止进程，升级后重新启动。插件仍可独立热更新。
- 更新为浅色学习壁纸，移除密保盘提示文字。GitHub workflows 不运行测试或安装 Playwright。

0.1.x 没有主程序更新入口，需要手动下载此安装包升级一次。此后可通过托盘安装签名主程序更新。插件配置与数据在覆盖安装时保留。

# 0.4.18

- 完整撤回此前为消除 loading 闪烁而修改的主应用、插件及 Web 界面行为，恢复原始请求状态、按钮、占位提示和插件页面加载流程；不再保留旧结果以掩盖加载过程。
- 删除勾勾/叉叉动画、共享 ActionButton 组件、包导出、可见变化对比与对应专属测试。请求取消、过期响应隔离、重复提交保护、业务错误显示及 CSP 安全引导不受影响。
- 系统信息、浏览器保护、密保盘分别更新到 1.0.4、1.3.1、1.1.2，确保已安装客户端能够收到界面回退。

- 遥测插件 1.2.4 默认只上报运行摘要。常规心跳、立即上报及远端刷新不再采集 Windows 权限、注册表安全描述符和系统审计，不再为遥测启动自启动状态查询 helper；保留计算机名与当前账户名用于设备辨认，停止上报累计 CPU 微秒计数，运行摘要不包含 SID、完整路径与错误原文。
- 完整诊断保留为插件界面内明确说明采集范围的手动操作；没有有效关联故障目标时，不查询审计策略、枚举日志通道或打开系统日志。移除遥测插件未使用的 process-control 授权，新插件要求宿主 0.4.18。

- 修复安装器在维护停止命令返回后，只检测一次残留进程就立即中止更新的问题。现在按条件等待主程序和控制器进程退出，每类进程最长等待 45 秒；没有残留进程时不额外延迟，不按名称强杀进程。
- 自动更新在应用文件替换开始前失败时，会尝试以全新的后台会话恢复未修改的旧程序。文件替换已开始时不会盲目启动可能不完整的安装目录；保留原始失败码，并记录恢复请求、进程创建或创建失败。
- 修复同一可执行文件通过长路径、DOS 短路径或命名空间前缀启动时的守护身份误判。该路径问题已独立复现，不将它认定为之前更新现场已证实的触发原因。
- 扩展现有 Windows CI 安装器可执行测试，覆盖真实同名进程退出等待、替换前失败恢复，以及手动安装和替换后的恢复禁止条件。

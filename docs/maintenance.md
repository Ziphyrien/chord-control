# 问题处理

## 打不开控制中心

在系统托盘中选择“重新连接”，连接恢复后再打开。启用应用保护时，完成密保盘验证即可进入。

## 插件无法启动

查看插件卡片上的原因。依赖被暂停时，先启动依赖；需要新版主程序时，在托盘菜单选择“检查并安装主程序更新”，完成后再到“插件”页面点击“检查更新”。详细记录在“活动”页面。

## 更新失败

插件更新失败时会尝试恢复原版本；恢复失败的插件可能暂时无法运行，请查看“活动”记录。如果提示资源清理失败，在托盘菜单选择“退出 Chord Control”，再重新启动。检查网络并处理错误后，到“插件”页面点击“检查更新”重试。

主程序更新失败时，先按[更新诊断](update-diagnostics.md)采集现场，再重试安装或重新启动。程序已经退出时，采集脚本仍可运行。启用应用保护时，托盘更新操作需要先打开并解锁控制中心。

## 查找和备份数据

在“设置 → 数据存储”点击“打开文件夹”。默认位置为 `%LOCALAPPDATA%\ChordControl`，插件数据位于 `data/<插件ID>/`。完整备份时，先退出应用，再复制数据目录。

忽略插件会保留其数据，并在列表中显示“已忽略”。点击“安装”可取消忽略，插件继续使用原数据目录；来源不可用时，需要等待来源恢复。

## 壁纸恢复失败

暂停学习权限会恢复原壁纸和相关设置。出现恢复错误时，保留插件数据目录，重新启动应用后再暂停。期间手动修改的设置会保留。

## 替换程序文件

先通过托盘退出应用。维护时也可在安装目录执行：

```text
chord-control.exe --maintenance-stop
```

命令成功结束后再替换文件。安装更新时，安装程序会自动完成退出和重新启动。

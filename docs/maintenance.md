# 问题处理

## 打不开控制中心

在系统托盘中选择“重新连接”，连接恢复后再打开。启用应用保护时，完成密保盘验证即可进入。

## 插件无法启动

查看插件卡片上的原因。依赖被暂停时，先启动依赖；需要新版主程序时，从托盘菜单更新 Chord Control，再检查插件更新。详细记录在“活动”页面。

## 更新失败

当前版本会继续保留。检查网络后再次点击“检查更新”。如果提示资源清理失败，通过托盘退出并重新启动。

## 查找和备份数据

在“设置 → 数据存储”点击“打开文件夹”。默认位置为 `%LOCALAPPDATA%\ChordControl`，插件数据位于 `data/<插件ID>/`。完整备份时，先退出应用，再复制数据目录。

移除插件会保留其数据。通过发布者提供的地址和公钥重新添加后，插件继续使用原数据目录。

## 壁纸恢复失败

暂停学习权限会恢复原壁纸和相关设置。出现恢复错误时，保留插件数据目录，重新启动应用后再暂停。期间手动修改的设置会保留。

## 替换程序文件

先通过托盘退出应用。维护时也可在安装目录执行：

```text
chord-control.exe --maintenance-stop
```

命令成功结束后再替换文件。安装更新时，安装程序会自动完成退出和重新启动。

# Chord Control

Windows 托盘工具，集中管理插件、自动同步更新，并提供密保盘和学习权限等功能。

## 安装与打开

1. [下载安装程序](https://github.com/Ziphyrien/chord-control/releases/latest/download/Chord.Control-setup.exe)并安装。安装完成后自动启动到系统托盘。
2. 在系统托盘中打开 Chord Control。
3. 首次启动会同步内置插件。插件和主程序默认每 5 分钟检查并自动安装更新；主程序更新在后台安装，完成后重新启动到托盘。

关闭主窗口会隐藏并锁定控制中心。登录启动、自动更新和检查间隔可以在“设置”中调整，退出应用请使用托盘菜单。

## 插件管理

| 操作 | 结果                                                             |
| ---- | ---------------------------------------------------------------- |
| 暂停 | 停止插件，保留安装和数据；有关联插件时显示一并暂停的名单。       |
| 启动 | 启动所选插件。依赖被暂停时，先启动依赖。                         |
| 忽略 | 停止插件，保留数据和列表项，关联插件暂停；后续同步不再自动安装。 |
| 安装 | 安装插件；对于已忽略的插件，取消忽略并恢复使用。                 |
| 更新 | 安装可用版本，失败时恢复原版本。                                 |

来源下架时保留本地安装；切换来源后，原插件保留原版本和发布者信息。添加其他插件需要发布者提供的插件地址与公钥。

## 内置功能

- **密保盘**：点击字符输入密码，最后点击 `＃` 确认。支持在完整密码前后加入虚位字符。
- **应用保护**：打开、退出或修改受保护设置时进行验证。
- **学习权限**：打开浏览器时进行验证，并固定使用 Windows 默认壁纸；暂停后恢复原设置。
- **系统信息**：查看设备信息，保存本机便笺。
- **运行遥测**：定期上传版本、插件状态与量化运行指标，支持远程立即采集。访问 [状态页面](https://chord.zipawa.top)，配置和指标见[遥测说明](docs/telemetry.md)。

每日密码是“月份与日期之和 + 星期英文首字母”。例如 3 月 15 日星期一为 `18M`。一次验证有效期为 120 秒，可尝试 5 次，最多输入 32 个字符。
